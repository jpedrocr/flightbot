# Screenshots Directory

Este diretório armazena screenshots capturados pelo Puppeteer durante o processo de web scraping.

Os screenshots são úteis para:
- Debug de problemas
- Visualização do estado da página
- Análise de seletores

Os arquivos principais são:
- `search-results.png` - Captura dos resultados da busca
- `error-state.png` - Captura do estado da página em caso de erro
