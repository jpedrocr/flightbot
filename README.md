# FlightBot

Um bot para informações e rastreamento de voos.

## Descrição

FlightBot é uma aplicação que permite aos utilizadores:
- Verificar informações de voos em tempo real
- Receber atualizações sobre atrasos e alterações
- Procurar voos disponíveis entre destinos
- Configurar alertas para voos específicos

## Instalação

```bash
# Clonar o repositório
git clone https://github.com/jpedrocr/flightbot.git

# Entrar no diretório
cd flightbot

# Instalar dependências
npm install
```

## Utilização

```bash
# Iniciar a aplicação
npm start
```

## Tecnologias

- Node.js
- Express
- APIs de informações de voo
- Banco de dados (a definir)
